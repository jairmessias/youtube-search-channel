# YouTube Search Channel

A modern web application to search for YouTube channels and view their details using the YouTube Data API v3.

## Features
- **Channel Search**: Search for channels by keyword.
- **Detailed Results**: View channel thumbnails, titles, descriptions, and subscriber counts.
- **Responsive Design**: Clean and modern UI that works on desktop and mobile.

## Prerequisites
- **YouTube Data API v3 Key**: You need an API key from the [Google Cloud Console](https://console.cloud.google.com/).

## Setup & Usage
1. Open `index.html` in your web browser.
2. Enter your API Key in the settings or prompt (to be implemented).
3. Start searching!

## Tech Stack
- HTML5
- CSS3 (Modern features like Flexbox/Grid)
- JavaScript (Vanilla ES6+)
